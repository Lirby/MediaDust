# MediaDust

MediaDust is a download manager for Downloading music and video
Its work with yt-dlp and ffmpeg

## Function

- parallel downloading
- Music in MP3, M4A, Opus, OGG, FLAC, WAV
- Video Quality in 144p, 240p, 360p, 480p, 720p, 1080p, 1440p, 2160p, 4320p
- Video format in MP4, MOV, MKV & WebM
- Downloading Playist
- Updates yt-dlp
